# Contributing

Contributions are welcome! If you have hunting queries, fingerprint patterns, or case studies to add:

1. **Fork** the repository
2. **Add** your queries to the appropriate file (SHODAN_QUERIES.md, CENSYS_QUERIES.md, or NETLAS_QUERIES.md)
3. **Test** your queries on the target platform before submitting
4. **Submit** a pull request with a clear description of what you're adding

## Guidelines

- Follow the existing format and structure
- Use Censys Platform syntax for CENSYS_QUERIES.md (see [Censys docs](https://docs.censys.com/docs/censys-platform-syntax-differences))
- For generic patterns (e.g. Werkzeug/Flask), note that they may produce many false positives
- Add both English and Turkish entries if possible (tr/ folder)
