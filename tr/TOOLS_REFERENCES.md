## Query Tablosu - Hızlı Referans

### Shodan

| Araç | Query |
|------|-------|
| AsyncRAT | `ssl.cert.subject.cn:"AsyncRAT Server"` |
| Mythic | `http.title:"Mythic"` |
| Havoc | `"X-Havoc: true"` |
| Sliver | `ssl.cert.issuer.cn:"operators"` |
| Cobalt Strike | `ssl.jarm:07d14d16d21d21d00042d41d00041d...` |
| GoPhish | `http.favicon.hash:803527991` |
| Metasploit | `http.title:"Metasploit"` |

### Censys

| Araç | Query |
|------|-------|
| AsyncRAT | `same_service(services.tls.certificates.leaf_data.issuer_dn="CN=AsyncRAT Server" and services.tls.certificates.leaf_data.subject_dn="CN=AsyncRAT Server")` |
| Mythic | `same_service(services.tls.certificates.leaf_data.subject.dn="O=Mythic" AND services.http.response.html_title="Mythic")` |
| Evilginx | `services.software.product: {Evilginx, EvilGoPhish}` |
